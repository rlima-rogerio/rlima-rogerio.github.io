# rlima-rogerio.github.io

Personal academic website of Prof. Rogerio R. Lima (DEE/UFMG): <https://rlima-rogerio.github.io>.

Minimal Jekyll site built by GitHub Pages. Most content is in `_data/*.yml`
(news, publications, people); see [AGENTS.md](AGENTS.md) for structure and conventions.

```bash
bundle install && bundle exec jekyll serve   # preview at http://127.0.0.1:4000
```
